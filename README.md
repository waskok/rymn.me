# Rymn Hub ✦ Personal Portfolio

A modern, fast, and responsive personal hub built. This project serves as the main entry point to my specialized service portfolios.

## Tech Stack
- **Framework:** React (Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React

## Local Development
1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

## Deployment
This project is optimized for static site generation (SSG) and can be easily deployed via FTP or modern platforms like Vercel/Netlify.
